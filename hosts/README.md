# Machine types and variants

Every directory here is a config for one machine type and variant, shared by all machines of that type.
The installer recognises the type by vendor and model. Machine names stay on the machines themselves.
This file is updated by `scripts/new-host.sh`.

| Config | Vendor | Model | Kind | Desktop | Apps | Encrypted |
|---|---|---|---|---|---|---|
| `lenovo-thinkbook-14-g2-itl-gnome-minimal-unencrypted` | Lenovo | ThinkBook 14 G2 ITL | Laptop | GNOME | minimal | no |
